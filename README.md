# DevSecOps Architect

Configurator that designs DevSecOps pipelines per organisation and project.

## Features

- Organisation and project setup
- Pipeline configurator
- Documentation and blog

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Zustand

## Getting Started

```bash
git clone https://github.com/ghostland-dev/auto-devsecops-architect.git
cd auto-devsecops-architect
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
